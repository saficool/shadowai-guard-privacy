ShadowAI Guard Privacy Policy

Effective 5 November 2026. This policy covers versions 0.1.0, 0.1.1, and 0.1.2 of the ShadowAI Guard browser extension. It does not describe any future web app or team service.

What the extension accesses

On the supported AI chat websites, ShadowAI Guard reads the text in a prompt when you try to send it. The prompt may contain personal information, payment or bank details, authentication secrets, or other text you entered. The extension checks that text for known patterns and displays masked matches and a risk score.

In version 0.1.2, clicking Restore values reads the latest visible AI reply with a known placeholder, or reads the reply text you selected, and shows a restored copy in the extension's panel. Version 0.1.1 reads only the text you selected for restoration. These versions do not rewrite the website's messages. In version 0.1.0, Restore values scans page text nodes and replaces placeholders inline, including in sent prompts. None of these versions reads your browser history, contacts, or files.

How the data is used and stored

Scanning and redaction run in your browser. When you choose Redact, the extension replaces detected values in the prompt with placeholders. The placeholder-to-original mapping is kept in the extension's memory for the current tab so it can restore values when you request it. The mapping is not saved to browser storage and is discarded when the page fully reloads or the tab closes. Versions 0.1.1 and 0.1.2 also clear it on the next extension action after you move to a different chat URL.

The current extension has no account, analytics, advertising, or extension-initiated network requests. It does not send prompt text, detected values, or usage events to the developer or another service.

What the AI website can receive

The AI website operates independently of ShadowAI Guard and may process a draft before you press Send. If you choose Send anyway, the website can receive the original prompt. If you redact and then send, the website receives the edited prompt, including any text the extension did not detect. In version 0.1.0, Restore values writes original values into the website's page, where its scripts may access them. In versions 0.1.1 and 0.1.2, viewing a restored copy in the extension panel does not edit the website's messages. If you copy or paste restored text into the website, its scripts may access that text. Consult that website's privacy policy for its practices.

Your choices

You can cancel the warning, redact detected values, or send the prompt anyway. Reloading the page or closing the tab clears the extension's in-memory restore mapping. In versions 0.1.1 and 0.1.2, moving to a different chat URL clears it when you next use the extension. Uninstalling the extension stops future scanning. These actions do not delete data already received by an AI website.

Limited use

ShadowAI Guard uses browser-accessible data only to scan and redact prompts and restore placeholders as described here. It does not sell data, use it for advertising, or permit the developer to read your prompts. Its use of information received from browser APIs follows the Chrome Web Store User Data Policy, including the Limited Use requirements.

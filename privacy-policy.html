ShadowAI Guard Privacy Policy

Effective 3 November 2026. This policy covers the current ShadowAI Guard browser extension. It does not describe any future web app or team service.

What the extension accesses

On the supported AI chat websites, ShadowAI Guard reads the text in a prompt when you try to send it. The prompt may contain personal information, payment or bank details, authentication secrets, or other text you entered. The extension checks that text for known patterns and displays masked matches and a risk score.

If you select Restore values, the extension reads text nodes on the current page to find placeholders and replaces them with the original values. It does not read your browser history, contacts, or files.

How the data is used and stored

Scanning and redaction run in your browser. When you choose Redact, the extension replaces detected values in the prompt with placeholders. The placeholder-to-original mapping is kept in the page's memory so the extension can restore values in visible replies. The mapping is not saved to browser storage and is discarded when the page fully reloads or the tab closes.

The current extension has no account, analytics, advertising, or extension-initiated network requests. It does not send prompt text, detected values, or usage events to the developer or another service.

What the AI website can receive

The AI website operates independently of ShadowAI Guard and may process a draft before you press Send. If you choose Send anyway, the website can receive the original prompt. If you redact and then send, the website receives the edited prompt, including any text the extension did not detect. If you choose Restore values, original values are written into the website's page, where the website's own scripts may access them. Consult that website's privacy policy for its practices.

Your choices

You can cancel the warning, redact detected values, or send the prompt anyway. Reloading the page or closing the tab clears the extension's in-memory restore mapping. Uninstalling the extension stops future scanning. These actions do not delete data already received by an AI website.

Limited use

ShadowAI Guard uses browser-accessible data only to scan and redact prompts and restore placeholders as described here. It does not sell data, use it for advertising, or permit the developer to read your prompts. Its use of information received from browser APIs follows the Chrome Web Store User Data Policy, including the Limited Use requirements.
